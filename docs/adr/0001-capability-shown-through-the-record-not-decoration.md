# Capability is shown through the Record, not decoration

The site's purpose is to make a hiring manager believe the author can build interfaces, and
its existing design language was a restrained "public financial record." Rather than
replacing that language with a conventional product-looking site, or bolting imagery,
cards, and scroll animations onto it, we decided to demonstrate capability *through* the
Record — with typographic scale, three deliberate layout tracks, Progressive quieting, and
a single inverted Evidence band — because a distinctive point of view executed precisely is
stronger evidence of craft than a generic page with more effects on it.

## Considered Options

- **Replace the concept.** A modern, product-feeling site with a bolder palette, cards, and
  depth. Higher ceiling on immediate "wow", but it discards a point of view that is
  genuinely earned by the subject matter (government property tax systems) and lands the
  site in the same visual space as every other developer portfolio.
- **Add material: imagery, texture, depth, a second accent.** Rejected because the strongest
  work has no publishable UI (`work.ts` marks Tax Bill Admin as "Internal — no public
  surface"), so the imagery would have to be decorative — decoration in a document that
  claims to be a verifiable record undermines the claim.
- **Make the Record operable** — sortable Ledger, resolvable citations, an embedded working
  artifact. Rejected as out of scope: with three work entries, interaction controls would be
  busywork, and the request was a visual redesign.

## Consequences

- The site will have no images. Every visual effect must be achieved with type, rule, space,
  ground, and track width. This is a constraint to design within, not an oversight to fix.
- Inversion is a scarce signal. There is exactly one inverted band, and it means "this is
  the proof." Adding a second inverted section later devalues the first.
- Motion is scarce for the same reason: one scroll-triggered moment on the Evidence band.
  Adding entrance animations elsewhere would flatten the hierarchy that Progressive quieting
  creates.
